# 鐵道進行式 Railway in Progress TW

> 看見台灣下一條鐵路，正在走到哪一步。

整合台灣捷運、臺鐵與高鐵建設計畫的公開進度網站。第一階段以六都捷運工程專責機關，以及交通部鐵道局為主要資料來源。

## 核心原則

1. **官方來源優先**：以各捷運工程局／工程處、交通部鐵道局資料為準。
2. **不製造進度百分比**：官方沒有公布百分比時，以建設階段呈現。
3. **主管機關導向**：捷運以主管工程機關收錄，不以行政區硬切；例如由新北捷運局推動的基隆捷運仍納入。
4. **可追溯**：每筆資料保留官方來源、官方資料日期、本站最後檢查時間。
5. **自動更新先審後發**：爬蟲資料會先驗證；來源格式異常時保留舊資料，不覆寫正式資料。

## 建設階段

`feasibility → comprehensive-planning → approved → design → tender → construction → testing → operating`

不同機關用語會映射至上述共同階段，同時保留官方原始文字。

## 技術方向

- Vite + React + TypeScript
- GitHub Pages
- GitHub Actions 自動部署
- 後續加入官方來源資料檢查／更新工作流
